## SFX / breaths / laughter (Hieu 22:05 + 22:19)
Spontaneous per character + scene — tables are DEFAULTS only, never stamps. Giggles (ふふっ/うふふ/んふふ) are LAUGHTER (e.g. Paulette "Fufu"/"Ufufu"), NEVER gasps ("Ư hự"). "Don't lose the sound" still holds (every JP sound must have a VN rendering). Default to staying as close to Japanese as possible; switch to pure Vietnamese ONLY when the Japanese-faithful rendering sounds too awkward. Vowel-length formula: VN vowel count = 1 + number of う/ぅ in JP. っ → Ư with matching punctuation; sentence-final emphatic っ attached to a word is NOT a gasp (never add Ư); っ inside words and already-rendered SFX excluded.
